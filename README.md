## 📖 Overview

**Personal Vault** (hosted at `ride-docs`) is a zero-dependency, serverless web interface built to aggregate, structure, search, and preview all key personal, family, vehicle, and academic documents stored on Google Drive. 

Live Demo: [shaztry.github.io/ride-docs](https://shaztry.github.io/ride-docs/)

---

## 🗂️ Categorized Document Hub

- 🪪 **Identity & Family Profiles:** Centralized quick access for Aadhaar cards across family members.
- 🎓 **Academic & Education Records:** Structured section for Marks Cards, Degree Certificates, and transcripts.
- 🏍️ **Vehicle & Transit Records:** Driving License (DL), Registration Certificates (RC), Insurance Policies, and Emission Certificates for two-wheelers (Apache RTR 160, Honda Activa).
- 📜 **Legal & Official Documents:** Affidavits, Name Change declarations, and official records.

---

## ✨ Key Technical Features

- ⚡ **Single-File Architecture:** Entire frontend engineered in a single `index.html` file combining CSS custom variables, UI components, and ES6+ application logic.
- 🔍 **Real-Time Instant Search:** Dynamic client-side search filtering across document names, categories, and family member profiles.
- 🖼️ **Embedded Drive Previewer:** Direct inline rendering using Google Drive `/preview` frames equipped with custom zoom controls (`+`, `-`, reset).
- 🌓 **Adaptive Theme Engine:** Dual Dark/Light theme switching built with pure CSS variables.
- 📱 **Responsive Mobile Drawer UI:** Smooth transition between document navigation drawers and preview mode on mobile viewports.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 Grid/Flexbox, Custom CSS Variables
- **Logic:** Vanilla JavaScript (ES6+)
- **Icons:** FontAwesome 6.4.0
- **Hosting:** GitHub Pages
- **Storage Backend:** Google Drive `/preview` Embedding
